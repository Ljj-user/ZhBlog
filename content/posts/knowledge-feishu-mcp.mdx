# 飞书 MCP 技能速览表

## 轻度润色版

这篇笔记是对飞书 MCP 能力的一份速览整理，方便快速查看它能做什么、适合用在哪些场景里。

我现在使用的是 `lark-cli 1.0.41`，并且已经完成用户态授权。当前可直接通过外部 Agent、MCP 或 CLI 调用飞书能力，去读、查、写、建、发、改。

### 技能速览表

| 能力域 | CLI 命令 | 能做什么 | 典型场景 |
| --- | --- | --- | --- |
| 通用 API | `api` | 直接调用开放接口 | 高级命令不够用时，补充任意 OpenAPI 调用 |
| 接口结构查询 | `schema` | 查看接口参数、字段和权限要求 | 写脚本前先查 API 结构和 scope |
| 认证授权 | `auth` | 登录、查看授权状态、查看 scopes | 给 CLI 绑定飞书账号 |
| 配置管理 | `config` / `profile` | 初始化应用、切换配置、管理 profile | 多账号、多应用、多环境切换 |
| 诊断与升级 | `doctor` / `update` | 检查配置、网络、版本，升级 CLI | 排查命令为什么不可用 |
| 联系人/用户 | `contact` | 查自己、搜用户、查基础资料 | 找同事、查 open_id、给后续动作做用户定位 |
| 日历 | `calendar` | 查日程、建会、改会、查忙闲、回 RSVP | 让 AI 帮忙排会、找空档、更新日历 |
| 文档 | `docs` | 读写文档内容、评论、权限、导入导出 | 自动写纪要、改文档、处理评论 |
| 云盘 | `drive` | 管理文件、上传下载、评论、权限 | 批量上传资料、拿文件链接、管理共享 |
| 知识库 | `wiki` | 读写知识库节点、空间、成员 | 建页面、搬运节点、维护知识库结构 |
| Markdown 文档 | `markdown` | 用 Markdown 创建或覆盖飞书原生文档 | 把 AI 生成内容直接写入飞书文档 |
| 表格 | `sheets` | 创建和读写电子表格 | 生成数据表、汇总统计、写入报表 |
| 幻灯片 | `slides` | 创建演示文稿、读写内容、增删页面 | 自动生成汇报 PPT、更新现有演示 |
| 多维表格/应用 | `base` | 管表、字段、记录、视图、仪表盘、流程 | 用 AI 驱动轻应用、表单、数据流转 |
| 即时消息 | `im` | 读消息、发消息、查群、管群成员、反应 | 自动发通知、读上下文、做消息流转 |
| 邮箱 | `mail` | 读邮件、读联系人、处理信箱内容 | 汇总邮件、提取待办、辅助回复 |
| 任务 | `task` | 管任务、子任务、任务列表、评论、附件 | 会议后拆任务、跟踪事项 |
| 审批 | `approval` | 读写审批实例和审批任务 | 审批状态追踪、流程处理辅助 |
| 考勤 | `attendance` | 查询考勤记录 | 做考勤查询、生成统计 |
| 会议与视频会议 | `vc` | 会议检索、会议事件、纪要、录制信息 | 查会议信息、读纪要、查录屏 |
| 会议纪要 | `minutes` | 搜会议纪要、上传内容 | 整理纪要、检索会议内容 |
| OKR | `okr` | 查目标、关键结果、对齐关系、进展 | 周报、月报、OKR 汇总与复盘 |
| 白板 | `whiteboard` | 创建与编辑白板内容 | 生成白板节点、组织脑图素材 |
| 事件订阅 | `event` | 消费与管理实时事件 | 做事件驱动自动化 |
| 应用开发 | `apps` | 开发、部署 HTML、网页和应用 | 搭飞书应用页面或配套前端 |

### 适合做什么

| 场景 | 可以怎么做 |
| --- | --- |
| 写文档 | 让 Agent 读取上下文后，直接写入飞书文档或 Wiki |
| 排会议 | 查参与人忙闲，给出候选时间并直接建会 |
| 生成报表 | 把数据写入飞书表格、多维表格或幻灯片 |
| 自动通知 | 根据任务状态、审批结果、会议结论自动发消息 |
| 项目助理 | 从文档或纪要提炼任务，再写进任务系统并提醒相关人 |
| 知识库维护 | 批量整理知识库、更新文档结构、迁移资料 |
| 邮件助手 | 汇总重点邮件、提取待办、生成回复草稿 |
| 流程自动化 | 串联审批、文档、消息、表格等能力完成完整流程 |

### 一句话理解

飞书 MCP 更像“让外部 AI 真正操作飞书”的执行层。它不只是回答问题，更适合做自动化、代理执行，以及跨文档、消息、日历、任务的流程编排。

## 结构优化版

如果把飞书内置 AI 助手看成“在飞书里和你对话的产品形态”，那飞书 MCP 更像“让外部 AI 真正去动手”的能力层。

我现在这套环境使用的是 `lark-cli 1.0.41`，已经完成用户态授权，当前状态可用。也就是说，外部 Agent 已经可以通过 CLI 或 MCP 去调用飞书能力，执行读、查、写、建、发、改这些动作。

### 2. 它有哪些能力

| 能力域 | CLI 命令 | 能做什么 | 典型场景 |
| --- | --- | --- | --- |
| 联系人和用户 | `contact` | 查自己、搜用户、查基础资料 | 找人、查 open_id、做用户定位 |
| 日历 | `calendar` | 查日程、建会、改会、查忙闲 | 安排会议、更新时间 |
| 文档和知识 | `docs` / `wiki` / `markdown` | 读写文档、评论、权限、知识库节点 | 写纪要、更新文档、维护知识库 |
| 文件 | `drive` | 上传、下载、共享、权限管理 | 管资料、拿文件、做共享 |
| 表格和幻灯片 | `sheets` / `slides` | 生成表格、汇总数据、制作演示 | 写报表、做汇报 |

| 消息和协作 | `im` / `mail` / `task` / `approval` | 发消息、读邮件、建任务、查审批 | 做通知、追事项、跟进流程 |
| 会议相关 | `vc` / `minutes` | 查会议信息、纪要、录制 | 会后整理、资料检索 |
| 组织目标与其他能力 | `okr` / `attendance` / `whiteboard` / `event` / `apps` | 查 OKR、查考勤、写白板、消费事件、开发应用 | 做组织管理和自动化扩展 |
| 兜底能力 | `api` / `schema` | 直调 API、查参数和权限 | 高级命令覆盖不到时补充调用 |

| 形态 | 更像什么 |

飞书 MCP 的价值在“替你动手”。
